# Terra NT Mobile v0.4 — Interactive Motion Build

A polished, mobile-first academic prototype for the PRT691 NT self-drive trip planner.

## Interaction upgrades
- Smooth SPA page transitions using View Transitions where supported
- Animated route drawing and map-pin entrances
- Drag-to-pan, wheel/pinch-style zoom, double-click zoom and recenter controls
- Interactive Route / Parks / Fuel / Permits layers
- Search autocomplete with photographic place results
- Place-detail bottom sheets with Google Maps action and Add to Trip
- Swipe/drag-down bottom sheets and evidence modal
- Tactile button/ripple feedback and optional device vibration
- Animated bottom-navigation active indicator
- Scroll-reveal and card micro-interactions
- Saved-inspiration heart toggle
- Animated save/remove/restore feedback via toast messages
- Custom map-layer panel and delete-data confirmation sheet
- Motion-aware loading state and animated switches
- Reduced-motion accessibility support

## Run
Open `index.html` in a browser or use the standalone HTML included in the downloadable package.

Prototype login: any valid email + any non-empty password.

## Map/data note
The in-app map is a Google-Maps-inspired local demo map, not Google Maps tiles. The Google Maps buttons open the real Google Maps website. Live API integration remains a later implementation step.
